# Scape-Invaders
Trabalho de Desenvolvimento de Jogos, por CARLOS ROBERTO DA SILVA, pela Universidade Federal de Juiz de Fora, com o docente MARCELO CANIATO RENHE.

Regras do jogo:
	-Você morre se qualquer inimigo te alcancar
	-Inimigos são barrados pelas portas
	-Ventoinhas são colocados no mapa para saltar entre plataformas
	
Objetivo:
	-Você é um astronauta em uma nave sendo invadida por alienígenas
	-Você precisa alcancar o escape pod para sair da nave
	-Em cada sala, você precisa recolher partes de uma chave eletrônica para abrir as portas entre as salas
	-Na sala final, onde há o escape pod, você precisa resolver um pequeno puzzle de código morse para abrir a porta do pod

O que deve ser implementado: 
	-Um cenário formado por plataformas e portas;
	-Movimentação do jogador pelas plataformas;
	-Portas que podem ser abertas e fechadas pelo jogador;
	-Inimigos com movimentação automática pelo cenário;
	-Possibilidade de utilizar portas para bloquear temporariamente os inimigos;
	-Objetos espalhados pelo cenário que devem ser coletados;
	-Câmera acompanhando o jogador, caso o cenário seja maior que a tela;
	-Condição de vitória/derrota: coletar todos os objetos ou ser atingido por um inimigo.
